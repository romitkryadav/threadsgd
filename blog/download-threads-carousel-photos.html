Photo and carousel guide

How to Download Photos from a Threads Carousel

Copy the link to the carousel post, preview the photo slides the tool can retrieve, and download the images you want individually.

Guide by ThreadsGrab · Updated November 20, 2026

What you need

A Threads carousel is a post with several media slides. To save its photos, copy the link to that specific post. A profile link only identifies the account, and a link to a reply may lead to a different part of the conversation. The post must be publicly viewable without signing in.

Good to know: the carousel tool displays photos it can retrieve as separate items. It does not combine them into a ZIP archive or provide one save-all button.

Download photos from a Threads carousel

  1. Open the carousel post. In Threads, find the post with the slides and use its share menu to copy the link. In a browser, copy the address of the post itself.
  2. Load the post in the tool. Open the Threads Carousel Downloader, paste the link, and choose Download. Wait for the previews to appear.
  3. Review the available slides. Check that the images belong to the post you intended. The order shown follows the media Threads provides for that post; if a slide is not listed, the tool may not be able to retrieve it.
  4. Save each photo you want. Select the download control on an image to save it as an individual file. You can download only selected slides or go through the full set one at a time.

How to keep several carousel downloads organized

Because each image downloads separately, your browser may save the files one by one or ask where each one should go. Before you start, decide whether to use the default Downloads folder or select a dedicated folder. After downloading, you can rename the files or move them together in your device’s file manager.

If your browser prompts for every download, follow the prompt rather than clicking repeatedly. Multiple clicks can create duplicate files. If a file appears to be missing, check the browser’s download history before trying again.

When a slide is missing or will not save

  • Make sure it is the carousel post URL. Copy the link from the post with the photos, not from the profile, a reply, or a quoted post.
  • Check visibility. Open the post while logged out. If it is private, removed, or otherwise restricted, the downloader cannot access it.
  • Check the media type. A video slide is not a still image. Use the Threads Video Downloader for video media.
  • Check the browser. If previews show but saving fails, allow downloads, check available storage, and look in Downloads. An in-app browser may handle files differently from Safari or Chrome.

Some slides may be unavailable even when other images from the same post load. The tool can show only media it can retrieve; it cannot restore an image that Threads no longer serves.

Image size and quality

Each saved photo is the version available from Threads for that post. The downloader does not enlarge the source or add detail that was not uploaded. If you zoom in and the image looks soft, that is a limit of the supplied file rather than a setting you can fix with a higher download option.

For a post with one photo, the Threads Image Downloader is a direct option. For profile avatars, use the Threads DP Downloader; a profile picture is separate from carousel media.

Use downloaded images responsibly

A public post can still contain work owned by its creator. Save images for purposes you are allowed to use, and get permission before reposting, editing, or using them commercially. Keep any creator credit that is part of the original image.
