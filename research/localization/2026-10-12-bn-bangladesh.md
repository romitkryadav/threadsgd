# Bengali (bn) localization research — 12 October 2026

- **Target market/language:** Bengali (bn), with Bangladesh as the primary language market. This is a language-targeting choice, not a claim about search volume.
- **Rotation source:** the ordered `LANGUAGES` list in `generate-sitemap.cjs`. The previous run targeted Arabic (`ar`), so Bengali (`bn`) is next. No separate locale-rotation state file was found in the repository tree.
- **Search-result review:** Bengali-language downloader pages use phrases such as `Threads ভিডিও ডাউনলোডার`, `ভিডিও ডাউনলোড করুন`, `ছবি ডাউনলোডার`, `লিংক পেস্ট করুন`, `পাবলিক পোস্ট`, and `GIF`. https://www.thredra.com/bn/ uses “Threads ভিডিও ডাউনলোডার” and “ভিডিও, ছবি ও GIF ডাউনলোড করুন”; https://www.reelget.com/bn uses “ভিডিও ডাউনলোডার” and “লিংক পেস্ট করুন”.
- **Preferred terminology:** “Threads ভিডিও ডাউনলোডার”; “Threads ছবি/ফটো ডাউনলোডার”; “Threads প্রোফাইল পিকচার (DP) ডাউনলোডার”; “Threads ফলোয়ার কাউন্টার” / “ফলোয়ার সংখ্যা”; “পাবলিক পোস্ট”; “প্রোফাইল লিংক”; “লিংক পেস্ট করুন”; “ছবি আলাদাভাবে ডাউনলোড করুন”.
- **Intent and content:** explain the task directly, public-only support, the difference between a post link and a profile link, and that GIFs are served as MP4 where relevant.
- **Claims to avoid:** no guaranteed HD/full-resolution output, no “unlimited” or “fastest” claims, no anonymity/zero-log guarantees, and no promise of exact real-time follower-count accuracy. The counter refreshes periodically, but results depend on public data Threads makes available.
- **Sources checked:** https://www.thredra.com/bn/ ; https://www.reelget.com/bn ; the current ThreadsGrab English homepage and current English video/image/profile-picture/follower-counter pages.
