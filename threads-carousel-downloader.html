How to Download Photos from a Threads Carousel

Copy the link to the public post, review the available photo slides, and save the images you need individually.

Copy the carousel post link

In Threads, open the post and choose Copy link from its share menu. Use the post link, not the creator's profile link.

Paste the link and load the slides

Paste the post URL in the box above and select Download. The page displays the photos it can retrieve as separate previews.

Choose photos to save

Preview the available slides and select the download button for each photo you want to keep. Each image downloads separately in the order Threads provides it.

Download Photos from a Threads Carousel

A Threads carousel can place several photos in one post. Paste that post's public link into the Threads carousel downloader to preview the images it can retrieve, then save the slides you want individually. You can use it when you need one photo or several, without installing an app or signing in to Threads.

This Threads carousel photo downloader focuses on image slides. It does not combine them into a ZIP file or offer a single save-all action. For a post with just one photo, use the Threads image downloader.

Copy the Link to the Carousel Post

Open the post containing the carousel in Threads and use its share menu to copy the link. Paste the post URL here; a profile link does not point to a particular carousel. Public post links from threads.com and threads.net are supported.

Check that the copied URL opens the original post. If you copied a reply or quote, return to the post with the photos and copy that link instead. The post needs to remain public and viewable without signing in.

Preview and Download Carousel Images

After you select Download, available photos appear as separate previews. Use the download control for each image you want to save. The downloads are individual files, so your browser may ask where to save each one or place them in its Downloads folder.

The tool only shows media it can retrieve from the post. A slide may not appear if it is unavailable or if it is a video rather than a photo. For video posts or video slides, open the Threads video downloader.

Photo Quality and Saving to Your Device

Each photo is supplied at the version available from Threads. The downloader does not upscale images or add a watermark, and it cannot restore details missing from the original. Any text or watermark already in the creator's image remains in the saved file.

On a computer or Android device, check your browser's Downloads folder. On iPhone or iPad, use the browser's share or save controls to place the image in Photos or Files if Safari opens a preview instead of saving it directly.

If a Carousel Photo Is Missing

  • Copy the link again from the original post and make sure it is not a profile, reply, or quote link.
  • Confirm that the post is public and opens without requiring a Threads login.
  • Reload the post if it was recently edited; removed or unavailable slides cannot be recovered by the downloader.
  • Use the video downloader for a carousel slide that contains a video rather than a photo.

Only save or share images when you have the right to do so. Please respect the creator's work and Threads' terms.
