Enter a Username or a Profile Link

You can type a username directly (with or without the @) or paste a full profile link copied from the Threads app or threads.net / threads.com — both point to the same account, so either works. A post link won't work here; if you're trying to save an image or video from inside someone's post rather than their avatar, use the Image Downloader or Video Downloader instead.

What You'll See Before You Download

Once the account is found, the tool shows the picture at the largest size available, along with the account's display name and a link back to the profile on Threads so you can confirm it's the right person before saving. Nothing downloads automatically; you choose when to save it.

Why the Same Account Can Return Different Picture Sizes

The picture you get back is whatever version Threads currently has stored for that account — it isn't upscaled or enhanced by this tool. Accounts that uploaded a large image will return a larger file; accounts that uploaded a small or older image will return a smaller one. There's no guaranteed resolution across every account, and any tool claiming a fixed size (like "always 4K") is describing something Threads doesn't actually provide.

When a Profile Picture Can't Be Retrieved

A picture won't load if the username doesn't exist, the account is private, or the account has never set a custom photo (in which case Threads' default placeholder avatar is what gets returned — which is expected behavior, not an error). Double-check the spelling of the username, or try pasting the profile link directly from the Threads app instead.

Saving the Picture on Your Phone

On iPhone, tapping Download File Now typically prompts Safari to save the image to Photos or Files, depending on your browser settings. On Android, the file goes to your default Downloads folder and is usually accessible from your gallery app shortly after. No app or extension is required on either platform.

A Note on Using Someone Else's Picture

A profile picture belongs to the person or brand who uploaded it. Downloading it here for personal reference, identification, or fair-use purposes is fine — reusing someone else's photo publicly (as your own avatar, in marketing, etc.) is a separate question of permission that this tool doesn't decide for you.
